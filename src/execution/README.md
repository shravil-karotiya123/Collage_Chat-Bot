# Isolated Code Execution Package (`src/execution/`)

## Purpose
The `src/execution/` package defines contracts for executing Python code generated by local models in a controlled, isolated sandbox.

## Security & Constraints
- **Subprocess Isolation**: Runs scripts as separate local processes with execution timeouts.
- **Resource Constraints**: Enforces execution timeouts and memory limits to prevent runaway scripts.
- **Local Artifact Capturing**: Captures stdout, stderr, exit codes, and output files directly into `outputs/`.
