# Document Generators Package (`src/generators/`)

## Purpose
The `src/generators/` package provides base interfaces for generating production industrial documents (Word `.docx` reports and Excel `.xlsx` spreadsheets).

## Output Targets
- **Word Document Reports**: Formatted industrial inspection reports, incident summaries, and executive notes.
- **Excel Spreadsheets**: Structured financial, material, equipment, and tabular data exports saved to `outputs/`.
