# Documents Directory (`documents/`)

## Purpose
The `documents/` directory acts as the local ingestion landing folder for raw industrial documents, technical manuals, PDF files, images, and data inputs.

## Guidelines
- **Supported File Extensions**: `.pdf`, `.docx`, `.xlsx`, `.png`, `.jpg`, `.jpeg`, `.csv`, `.txt`, `.json`.
- **Confidentiality**: Files placed here are processed strictly offline. No telemetry or external cloud transfers occur.
- **Git Status**: Contents are ignored by `.gitignore` except for this `README.md` file.
